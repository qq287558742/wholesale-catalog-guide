# Reading a Wholesale Catalog

Unit economics for independent retailers: which catalog fields actually decide whether a
SKU survives two seasons.

- **Case pack** decides the real commitment, not the unit cost.
- **Unit dimensions and weight** decide freight and shelf space.
- **Reorder rate** is the only field measuring a decision someone already repeated.
- **Return rate** is a cost of goods, not a customer-service metric.
- **Size consistency** decides whether the customer comes back.
